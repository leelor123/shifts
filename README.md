# מעקב משמרות ושכר — PWA אישית

אפליקציה למעקב משמרות, חישוב שכר (שבתות, חגים, שעות נוספות, נסיעות, נטו משוער), התראות חכמות וניתוח תלושים.
הכול רץ בטלפון ועובד גם בלי אינטרנט. הנתונים נשמרים במכשיר (IndexedDB) ולא נשלחים לשום שרת.

## מה יש בתיקייה

| נתיב | תפקיד |
|---|---|
| `docs/` | **האתר עצמו** (GitHub Pages מגיש את התיקייה הזו): `index.html` (כל האפליקציה בקובץ אחד), `sw.js` (עבודה אופליין ועדכונים), `manifest.webmanifest`, אייקונים |
| `src/core/` | מנוע החישוב: לוח עברי וחגים, זמני שבת לפי עיר, שכר, תובנות, ניתוח תלושים |
| `src/app/` | ממשק המשתמש |
| `tests/` | בדיקות אוטומטיות (`node tests/run.js`) |
| `tools/build.js` | בונה את `docs/` מקובצי המקור |

> למה לא רק קובץ HTML אחד? כדי שאפשר יהיה להתקין את האפליקציה ושהיא תעבוד אופליין, הדפדפן דורש service worker בקובץ נפרד וקובץ manifest. כל הקוד עצמו נמצא ב-`index.html`.

## שלב 2: התקנה בגלקסי S26 Ultra

1. פתח את הכתובת ב-**Chrome**, לא ב-Samsung Internet.
2. בפתיחה הראשונה עבור על אשף ההגדרה, או לחץ "נסה עם נתוני דוגמה".
3. תפריט **⋮ ← הוספה למסך הבית ← התקנה**. אם Chrome מציע "התקן אפליקציה", אפשר ללחוץ ישר.
4. האייקון יופיע במסך הבית. לחיצה ארוכה עליו נותנת קיצורים: **"התחל משמרת"** ו-**"הוסף משמרת"**.
5. כשהאפליקציה תבקש לשלוח התראות, אשר.
   - כדי שתזכורות יגיעו גם כשהאפליקציה סגורה: **הגדרות הטלפון ← אפליקציות ← Chrome ← סוללה ← ללא הגבלה**.
6. בהגדרות האפליקציה, תחת **אודות**, אמור להופיע "אחסון קבוע: כן ✓". זה אומר שהדפדפן לא ימחק את הנתונים כשהמכשיר מתמלא.

## שלב 3: גיבוי

- **הגדרות ← גיבוי ושחזור ← "גבה ושתף ל-Drive"**. בחלון השיתוף בחר Google Drive.
- הגיבוי האוטומטי (ברירת מחדל: כל שבוע) מוריד קובץ לתיקיית ההורדות כשפותחים את האפליקציה.
- מעבר לטלפון חדש או לכתובת חדשה: התקן את האפליקציה במקום החדש, ואז **שחזור ← בחר את קובץ הגיבוי ← החלפה מלאה**.

## עדכון גרסה (בלי לאבד נתונים)

1. משנים את הקוד ב-`src/` ומריצים `node tools/build.js`. הבנייה מעדכנת את `docs/`.
2. מעלים את השינויים למאגר: `git add -A`, `git commit`, `git push`. אחרי דקה-שתיים GitHub Pages מעדכן את האתר.
3. בפתיחה הבאה של האפליקציה מופיע "גרסה חדשה זמינה — **עדכן**". הנתונים נשארים.

## הערות ומגבלות

- **שעון קיץ/חורף:** המשמרות נשמרות כזמנים מוחלטים, ולכן משמרת בלילה של מעבר השעון נספרת לפי השעות שעבדת בפועל (9 או 7 שעות).
- **זמני שבת:** מחושבים בטלפון בשיטת NOAA. נבדקו מול hebcal: הפרש של עד דקה. הלוח העברי והחגים נבדקו מול hebcal לשנים 2015–2040.
- **שעות נוספות** נספרות לפי יום עבודה, כלומר כל המשמרות שמתחילות באותו תאריך. שעות נוספות שבועיות (מעל 42) לא מחושבות.
- **קריאת תלושים:** PDF נקרא עם pdf.js, ותמונה מזוהה עם OCR בעברית (tesseract.js). בשימוש הראשון הרכיבים יורדים מהאינטרנט (כ-10MB ל-OCR), ואחר כך עובדים גם אופליין. תמיד כדאי לעבור על מסך האימות.
- **ניתוח AI (אופציונלי):** נשלח רק טקסט שעבר הסתרה אוטומטית (ת״ז, בנק, כתובת, טלפון ואימייל), ורק אחרי שראית אותו ואישרת. המפתח נשמר רק בטלפון ולא נכלל בגיבויים. ברירת המחדל היא Claude Opus 5.5, ואפשר לבחור Sonnet 5.5 או Haiku 5.5. החיבור ל-API נבדק עם מפתח לא תקין (שגיאה 401 מטופלת), אבל לא נבדק עם מפתח אמיתי.
- **תזכורות כשהאפליקציה סגורה:** Chrome בודק מדי פעם (Periodic Background Sync), ולא בדיוק לדקה. לתזכורת מדויקת לפני משמרת: לוח שנה ← ייצוא ליומן, או "הוסף ל-Google Calendar" מתוך המשמרת.
- **PDF:** הדוח נוצר דרך חלון ההדפסה של הטלפון ← "שמור כ-PDF".
- **נעילה בקוד** מונעת הצצה, אבל הנתונים עצמם לא מוצפנים.
- כל החישובים (נטו, מס, זכויות, החזר מס) הם **הערכה** ולא ייעוץ משפטי או חשבונאי.

## למפתחים

```bash
node tests/run.js        # 63 בדיקות: חצות, שבת, ש״נ בשבת, שינוי תעריף, שעון קיץ/חורף, עקיפות, ממוצעים, תלושים
node tools/build.js      # בונה את docs/
node tools/serve.js      # שרת מקומי ל-docs/: http://localhost:8765
```

- **גרסה:** `version` ב-`package.json`. מוצגת בהגדרות, ונכנסת לשם ה-cache של ה-service worker.
- **הגירת נתונים:** כשמשנים מבנה של רשומות, מעלים את `SCHEMA_VERSION` ב-`src/app/store.js` ומוסיפים פונקציה ל-`MIGRATIONS`. ההגירה רצה בטעינה ובשחזור גיבוי ישן.
- **מאגרים ב-IndexedDB:** כדי להוסיף מאגר חדש, מעלים את `DB_VERSION` ומוסיפים את שמו ל-`STORES`. מאגרים קיימים לא נמחקים.
