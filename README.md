# מעקב משמרות ושכר — PWA אישית

אפליקציה למעקב משמרות, חישוב שכר (שבתות, חגים, שעות נוספות, נסיעות, נטו משוער), התראות חכמות וניתוח תלושים.
האפליקציה עובדת גם בלי אינטרנט. הנתונים נשמרים בטלפון (IndexedDB), ואחרי התחברות עם Google — גם בחשבון בענן (Firebase, אזור תל אביב), עם סנכרון בין מכשירים.

## מה יש בתיקייה

| נתיב | תפקיד |
|---|---|
| `docs/` | **האתר עצמו** (GitHub Pages מגיש את התיקייה הזו): `index.html` (כל האפליקציה בקובץ אחד), `sw.js` (עבודה אופליין ועדכונים), `manifest.webmanifest`, אייקונים |
| `src/core/` | מנוע החישוב: לוח עברי וחגים, זמני שבת לפי עיר, שכר, תובנות, ניתוח תלושים |
| `src/app/` | ממשק המשתמש |
| `tests/` | בדיקות אוטומטיות (`node tests/run.js`) |
| `tools/build.js` | בונה את `docs/` מקובצי המקור |
| `firestore.rules` | כללי האבטחה של מסד הנתונים: כל משתמש ניגש רק לנתונים שלו |
| `tools/fbapi.js` | כלי ניהול ל-Firebase (הפעלת שירותים, דומיין מאושר, בדיקת כללי אבטחה) |
| `tools/legal-pages.js` | יוצר את הדפים הציבוריים: פרטיות, תנאי שימוש, נגישות, מחיקת חשבון (חלק מה-build) |
| `tools/android.js`, `android/` | בניית אפליקציית האנדרואיד ל-Google Play (Trusted Web Activity) |
| `store/` | **העלאה ל-Google Play**: המדריך [`store/PLAY_STORE.md`](store/PLAY_STORE.md), טקסטים, צילומי מסך ותמונת נושא |

> למה לא רק קובץ HTML אחד? כדי שאפשר יהיה להתקין את האפליקציה ושהיא תעבוד אופליין, הדפדפן דורש service worker בקובץ נפרד וקובץ manifest. כל הקוד עצמו נמצא ב-`index.html`.

## אפליקציה ב-Google Play

אפליקציית האנדרואיד היא "מעטפת" (Trusted Web Activity) שפותחת את האתר הזה במסך מלא, ולכן כל עדכון שנדחף לכאן מגיע גם אליה בלי העלאה חדשה לחנות.
המדריך המלא להעלאה: **[store/PLAY_STORE.md](store/PLAY_STORE.md)**.
מפתח החתימה נשמר מחוץ למאגר, ב-`%USERPROFILE%\ShiftPay-Android\keys` — לגבות ולא להעלות לשום מקום.

## התחברות עם Google וסנכרון בענן

- פרויקט Firebase: `shiftpay-70ab6`. מסד נתונים Firestore באזור `me-west1` (תל אביב). כללי האבטחה בקובץ `firestore.rules`, ונבדקו ב-12 תרחישים (`node tools/fbapi.js ruletest shiftpay-70ab6`).
- מבנה הנתונים: `users/{uid}/{store}/{id}` = `{u: updatedAt, d: נמחק?, j: JSON}`. גרסה חדשה תמיד גוברת. כללי האבטחה מונעים מטלפון שהיה מנותק לדרוס שינוי חדש יותר. מחיקות עוברות כמצבה (tombstone).
- לא עולה לענן: מפתח ה-API, קוד הנעילה, קובצי התלושים והטקסט הגולמי שלהם.
- **ההתחברות הופכת לחובה רק כשהיא מוגדרת.** בכל פתיחה האפליקציה בודקת אם התחברות Google פעילה לכתובת. אם לא — היא ממשיכה לעבוד מקומית, כך שאף פעם לא ננעלים בחוץ. בהתחברות הראשונה, מה שכבר יש בטלפון עולה לחשבון.

### הפעלת ההתחברות (פעם אחת, במסוף Firebase)
1. [Authentication](https://console.firebase.google.com/project/shiftpay-70ab6/authentication) ← **Get started** ← **Google** ← **Enable** ← בחר אימייל תמיכה ← **Save**.
2. באותו מסך: **Settings** ← **Authorized domains** ← **Add domain** ← `leelor123.github.io` ← **Add**.

## שלב 2: התקנה בגלקסי S26 Ultra

1. פתח את הכתובת ב-**Chrome**, לא ב-Samsung Internet.
2. בפתיחה הראשונה עבור על אשף ההגדרה, או לחץ "נסה עם נתוני דוגמה".
3. תפריט **⋮ ← הוספה למסך הבית ← התקנה**. אם Chrome מציע "התקן אפליקציה", אפשר ללחוץ ישר.
4. האייקון יופיע במסך הבית. לחיצה ארוכה עליו נותנת קיצורים: **"התחל משמרת"** ו-**"הוסף משמרת"**.
5. כשהאפליקציה תבקש לשלוח התראות, אשר.
   - כדי שתזכורות יגיעו גם כשהאפליקציה סגורה: **הגדרות הטלפון ← אפליקציות ← Chrome ← סוללה ← ללא הגבלה**.
6. בהגדרות האפליקציה, תחת **אודות**, אמור להופיע "אחסון קבוע: כן ✓". זה אומר שהדפדפן לא ימחק את הנתונים כשהמכשיר מתמלא.

## הערות ומגבלות

- **שעון קיץ/חורף:** המשמרות נשמרות כזמנים מוחלטים, ולכן משמרת בלילה של מעבר השעון נספרת לפי השעות שעבדת בפועל (9 או 7 שעות).
- **זמני שבת:** מחושבים בטלפון בשיטת NOAA. נבדקו מול hebcal: הפרש של עד דקה. הלוח העברי והחגים נבדקו מול hebcal לשנים 2015–2040.
- **שעות נוספות** נספרות לפי יום עבודה, כלומר כל המשמרות שמתחילות באותו תאריך. שעות נוספות שבועיות (מעל 42) לא מחושבות.
- **קריאת תלושים:** PDF נקרא עם pdf.js, ותמונה מזוהה עם OCR בעברית (tesseract.js). בשימוש הראשון הרכיבים יורדים מהאינטרנט (כ-10MB ל-OCR), ואחר כך עובדים גם אופליין. תמיד כדאי לעבור על מסך האימות.
- **ניתוח AI (אופציונלי):** נשלח רק טקסט שעבר הסתרה אוטומטית (ת״ז, בנק, כתובת, טלפון ואימייל), ורק אחרי שראית אותו ואישרת. המפתח נשמר רק בטלפון ולא נכלל בגיבויים. ברירת המחדל היא Claude Opus 5.5, ואפשר לבחור Sonnet 5.5 או Haiku 5.5. החיבור ל-API נבדק עם מפתח לא תקין (שגיאה 401 מטופלת), אבל לא נבדק עם מפתח אמיתי.
- **תזכורות כשהאפליקציה סגורה:** Chrome בודק מדי פעם (Periodic Background Sync), ולא בדיוק לדקה. לתזכורת מדויקת לפני משמרת: לוח שנה ← ייצוא ליומן, או "הוסף ל-Google Calendar" מתוך המשמרת.
- **PDF:** הדוח נוצר דרך חלון ההדפסה של הטלפון ← "שמור כ-PDF".
- **נעילה בקוד** מונעת הצצה, אבל הנתונים עצמם לא מוצפנים.
- כל החישובים (נטו, מס, זכויות, החזר מס) הם **הערכה** ולא ייעוץ משפטי או חשבונאי.

## תכונות נוספות (גרסה 1.1)

- **עוזר זכויות ושכר (AI):** צ'אט שעונה על שאלות על זכויות בעבודה, התלוש והאפליקציה. אפשר לצרף סיכום מספרי של הנתונים, בלי פרטים מזהים. דורש מפתח API אישי של Anthropic (הגדרות › מפתח AI). ההיסטוריה נשמרת בטלפון.
- **פרטים אישיים:** שם ותאריך לידה (לא חובה). ביום ההולדת מופיעה ברכה. מתחת לגיל 18 הנטו שווה לברוטו: אין מס הכנסה, ביטוח לאומי, מס בריאות ופנסיה. גם ניתוח התלוש מתריע אם נוכו לנער/ה ביטוח לאומי או מס.
- **מידע משפטי:** תנאי שימוש, מדיניות פרטיות, הבהרה משפטית, הצהרת נגישות, רישיונות ואודות (הגדרות › מידע משפטי). בכניסה מאשרים את התנאים פעם אחת, ושוב רק כשהם משתנים.
- **עיצוב:** IBM Plex Sans Hebrew ו-Frank Ruhl Libre, פלטת "דף חשבון" (פטרול וענבר), ותנועה שמתאימה לכיוון ימין-לשמאל.

> המסמכים המשפטיים נכתבו כתבנית מקצועית, אבל אינם תחליף לבדיקה של עורך דין, במיוחד לפני הפצה לציבור רחב.

## למפתחים

```bash
node tests/run.js        # 74 בדיקות: חישובים, ממוצעים, תלושים, גיל, וסנכרון בין כמה טלפונים מדומים
node tools/build.js      # בונה את docs/
node tools/serve.js      # שרת מקומי ל-docs/: http://localhost:8765
```

- **גרסה:** `version` ב-`package.json`. מוצגת בהגדרות, ונכנסת לשם ה-cache של ה-service worker.
- **הגירת נתונים:** כשמשנים מבנה של רשומות, מעלים את `SCHEMA_VERSION` ב-`src/app/store.js` ומוסיפים פונקציה ל-`MIGRATIONS`. ההגירה רצה בטעינה ובשחזור גיבוי ישן.
- **מאגרים ב-IndexedDB:** כדי להוסיף מאגר חדש, מעלים את `DB_VERSION` ומוסיפים את שמו ל-`STORES`. מאגרים קיימים לא נמחקים.
